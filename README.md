# Реализация архитектур нейронных сетей на C++ с нуля (From Scratch)

Данный репозиторий содержит независимые низкоуровневые реализации ключевых архитектур глубокого обучения на языке C++. Цель проекта — декомпозиция алгоритмов до базовых математических операций и понимание механики работы нейросетей без использования готовых ML-фреймворков.

Вся логика — от прямого прохода (Forward Pass) до обратного распространения ошибки (Backpropagation) и работы оптимизаторов — написана вручную с использованием стандартной библиотеки (STL).

## Архитектура репозитория и ветвление

Каждая модель разрабатывается изолированно в соответствующей ветке Git. Исходный код разбит на логические модули (`.cpp` и `.h` файлы), распределенные по директориям.

* **MLP (Multilayer Perceptron):** Полносвязная нейронная сеть. Реализованы кастомные слои (Dense), функции активации (ReLU, Sigmoid, Softmax), вычисление матричных производных и градиентный спуск (SGD). Данные для обучения генерируются программно в виде набора логов перед началом сессии.
* **CNN (Convolutional Neural Network):** Сверточная нейронная сеть (в процессе доработки). Ручная реализация операции свертки (Convolution Layer), подвыборки (Pooling Layer) и выпрямления тензора (Flatten Layer).

*Вектор дальнейшего развития (структурные ветки подготовлены):*
* **RNN (Recurrent Neural Network):** Рекуррентные архитектуры и управление скрытым состоянием (Hidden State).
* **Transformer:** Реализация механизмов внимания (Self-Attention, Multi-Head Attention).

## Технический стек и особенности реализации
* **Язык разработки:** C++ (стандарт C++17 / C++20).
* **Работа с данными:** Обучающая выборка для MLP формируется программно через генерацию логов. Для загрузки изображений в CNN используется header-only библиотека `stb_image`, которая преобразует графические файлы в сырые массивы пикселей.
* **Линейная алгебра:** Все операции над матрицами и тензорами (умножение, транспонирование) написаны вручную через контейнеры STL без привлечения сторонних библиотек (Eigen, BLAS и др.).
* **Система сборки:** Кроссплатформенная автоматизация компиляции реализована с помощью **CMake**.

## Сборка и запуск

Для сборки проекта необходим компилятор с поддержкой C++17 (или выше) и установленный CMake. Перед сборкой убедитесь, что вы переключились на ветку интересующей вас архитектуры (`git checkout <название_ветки>`).

```bash
mkdir build && cd build
cmake ..
cmake --build .
```
